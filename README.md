XMultistep Form

Project Overview

XMultistep Form is a responsive multi-step form application that allows users to enter personal details, select subscription plans, choose add-ons, and review their order before confirmation.

Technologies Used

- HTML5
- CSS3
- JavaScript

Features

- Multi-step form navigation
- Personal information form
- Subscription plan selection
- Add-on selection
- Order summary
- Form validation
- Responsive design for desktop and mobile devices

Project Structure

- "index.html" – Main application structure
- "style.css" – Styling and responsive design
- "script.js" – Application functionality
- "assets/" – Project assets

How to Run

1. Clone or download this repository.
2. Open "index.html" in your browser.
3. Navigate through the multi-step form.
